# Итераторы в двоичном дереве поиска

Реализовать множество (контейнер, аналогичный std::set) с итераторами.
Итератор, как минимум, должен позволять использовать неизменяющие алгоритмы стандартной библиотеки.

Проиллюстрировать работоспособность на примере алгоритмов std::find и std::count_if (напишите тесты).

Заготовка представлена в двух вариантах: BinTree и BinTree_with_implementation. В одном находятся только объявления, в другом присутствует частичная реализация некоторых методов и работа с аллокаторами. Тесты в заготовке представлены для set, map, multiset и multimap и для проверки работы с объектами без конструктора (Elem). В данной лабораторной должны проходить тесты для set и Elem, остальные тесты нам пригодятся позже.

Заготовку выбрать самостоятельно.
